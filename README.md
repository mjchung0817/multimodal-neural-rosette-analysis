# Multimodal Workflow for Neural Rosette Analysis

Companion code for multimodal spatial analysis of neural rosette formation in iPSC-derived cultures, integrating MALDI mass spectrometry imaging with immunofluorescence markers.

## Repository Structure

### 1. [UMAP Pipeline](umap-pipeline/)
Single-cell MALDI-MS clustering and visualization pipeline (PCA → kNN → Leiden → UMAP) for identifying metabolically distinct subpopulations within rosette-bearing cultures.

### 2. [Neural Rosette Detection and Validation](neural-rosette-detection-and-validation/)
Detection and validation of neural rosette structures from immunofluorescence and MALDI imaging data.

### 3. [Rosette Center-to-Edge Spatial Analysis](rosette-center-to-edge-spatial-analysis/)
Radial gradient quantification of metabolite distributions within neural rosettes, including permutation-based statistical testing of lumen-enriched m/z features.
